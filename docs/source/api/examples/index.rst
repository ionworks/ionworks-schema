Examples
========

Worked examples that build a fit with ``ionworks-schema``, submit it through the
``ionworks`` API client, and read the typed result. Each example is a runnable
script exercised in CI, so the code here always matches a passing run.

These examples plot their fit, which needs the optional plotting
dependency: install ``ionworks-schema[plot]``.
